# Задание 5 — SASS

Адаптивная страница digital-агентства «Борщ».

## Структура
- `index.html` — разметка страницы.
- `scss/style.scss` — исходный SASS.
- `css/style.css` — скомпилированные стили, подключённые в HTML.
- `js/main.js` — логика мобильного меню.

## Что реализовано на SASS
- Массив изображений `$list-img-circle` с обязательными именами.
- Миксин `@mixin flexible()` для Flexbox-центрирования.
- Цикл `@for` для шахматного расположения четырёх секций.
- Цикл `@for` для пяти круглых изображений внизу.
- Переменные, вложенные правила и адаптивные media queries.

## Запуск
Откройте проект в VS Code, установите **Live Sass Compiler**, откройте `scss/style.scss` и нажмите **Watch Sass**. CSS сохраняется в `css/style.css`. Для просмотра откройте `index.html` через Live Server. Изображения и шрифты загружаются из интернета.
